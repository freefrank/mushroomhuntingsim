# 菌踪 · 玩法扩展设计文档

> 本文档是六个玩法阶段的**开发规格书**。开发按阶段顺序进行，每阶段独立可玩、独立验收。
> 阶段顺序：**P1 市集+委托 → P2 鉴别/相似种 → P3 猎菇犬+工具店 → P4 新鲜度+一天一局 → P5 烹饪 → P6 品质/变异/拍照**

---

## 0. 架构约束（所有阶段必须遵守）

1. **纯前端、零构建、零依赖**。经典 `<script>` 顺序加载（非 ES module），顶层 `let/const` 跨文件共享全局词法作用域。新增文件须在 `index.html` 中按依赖顺序插入。
2. **所有美术运行时程序化绘制**（Canvas 2D 矢量 + 渐变），风格与现有 `js/mushrooms.js` / `js/player.js` 的手绘水彩风一致。禁止外部图片。
3. **帧率无关**：一切随时间的运动/计时必须乘 `dtf`（见 `js/render.js`）。
4. **存档兼容**：存档 key 保持 `mh3:save`，新增字段 `v:2`。`load()` 遇到旧档（无 `v`）需迁移：旧 `basket`（数字）丢弃归零，其余字段保留。所有新字段在 `load()` 中必须有默认值兜底。
5. **移动端优先**：所有新 UI 必须在窄屏（375×667）可用；新按钮放入现有 `#actions` 行或模态框内；触屏没有 hover/右键，交互需给出触屏等价物。
6. **文案全部中文**，语气与现有文案（山林随笔风）一致。
7. **测试钩子**：每阶段把新系统挂到 `window.__mh`（见各阶段"验收钩子"），验收用 Playwright 无头跑。
8. 不修改部署工作流；不动 `assets/bgm`。

### 0.1 全局数据改造（P1 落地，后续阶段复用）

**背包从数字变为物品数组**。`state` 新增/修改：

```js
state.coins = 0;             // 金币
state.inv   = [];            // 背包物品：{id, q:1, fr:1, var:null, day:0}
                             //  id=物种id  q=品质(1/2/3, P6用, 先固定1)
                             //  fr=新鲜度0..1(P4用, 先固定1)  var=变异(P6)  day=采摘日(P4)
state.cap   = 25;            // 背包容量（P3 可升级）
state.day   = 1;             // 天数（P4 正式使用；P1 起每次「深入林间」+1）
state.orders= [];            // 委托单（P1）
state.tools = {};            // 已购工具（P3）{dog:true,...}
state.buffs = {};            // 烹饪增益（P5）{speed:1.15, until:day}
state.cooked= [];            // 已做过的菜（P5）
state.stats = {sold:0, earned:0, ordersDone:0, mimicCaught:0, mimicFooled:0};
```

HUD 的 `#basketN` 显示 `inv.length`，旁边新增金币徽章 `🪙 <b id="coinN">`。
`save()/load()` 序列化以上全部字段（Set 转数组）。

### 0.2 小屋（统一容器 UI）

新增模态 `#hutModal`「山脚小屋」，顶部页签：**出售 · 委托**（P1）→ 加 **道具店**（P3）→ 加 **灶台**（P5）。
`#actions` 行新增按钮 `🏠 小屋`（放在「深入林间」之后）。样式复用现有 `.modal/.panel/.filters` 体系。

## P1 市集 + 委托（给篮子意义）

### 1.1 定价

```
基础价 basePrice(sp) = [3, 8, 20, 50, 120][sp.r]
食性系数: edible ×1.0 | careful ×0.8 | med ×1.5 | inedible ×0.3 | poison ×0.5 | deadly ×0.6
```

毒菇/剧毒由「药铺」代收（出售行显示 ⚗ 药铺收购 字样，纯风味）。
**时价**：每天（每次 newField）用 `mulberry32(hash('px'+state.day))` 为每个物种生成 0.8–1.4 的当日系数，市集列表显示 ↑↓ 箭头（≥1.15 红↑，≤0.9 绿↓）。
单价 = round(基础价 × 食性 × 时价 × q × (0.4+0.6×fr))（q、fr 本阶段恒为 1）。

### 1.2 出售页签

- 按物种聚合列出背包内容：小图（`spriteURL`）、名称、数量、单价、「卖出」按钮；顶部「一键全卖」。
- 卖出：金币入账（飘字 +N 🪙），`state.stats.sold/earned` 累计，存档。
- 空背包显示引导文案。

### 1.3 委托页签

- 固定 3 个委托槽。委托生成规则：
  - 物种池 = 已解锁环境 ∩ 当前季节可产（`sp.seasons.includes(state.season)`），排除 grove 幻想菇与 deadly；
  - 数量 = 稀有度 r0-1:3~4 朵，r2:2 朵，r3+:1 朵；
  - 报酬 = ceil(单价基准 × 数量 × 1.8) + 稀有度小费；
  - 每单剩余天数 3 天（`expires = state.day+3`），过期自动作废重开新单；
  - 委托文案带 NPC 风味（如「药铺伙计：师傅抓药要 2 朵灵芝，价钱好说。」），写 8-10 个 NPC 模板随机套。
- 交付按钮：背包够数才可点；交付扣物品、得报酬、`ordersDone++`、立即补一张新单。
- 换季/换环境导致委托不可能完成没关系——会自然过期。

### 1.4 容量

背包满（`inv.length>=state.cap`）时采集被阻止：toast「篮子满了，去小屋卖掉些吧」。HUD 显示 `n/25`。

### 1.5 成就（追加到 ACH）

`首笔生意`（第一次卖出）、`小有积蓄`（累计赚 500）、`金字招牌`（完成 10 单委托）。

### 1.6 验收钩子

`window.__mh` 增加：`coins()=>state.coins, inv:()=>state.inv, orders:()=>state.orders, sellAll(), openHut(), deliver(i), priceOf(id)`。

### 1.7 验收标准（Fable 执行）

- 采 3 朵 → 开小屋 → 全卖：金币=Σ单价，背包清空，HUD 同步；
- 委托 3 张合法（物种当季可得、非 deadly/grove）；交付一单金币增加、补新单；
- 背包 25 满时无法继续采集且有提示；
- 刷新页面后 coins/inv/orders 完整恢复；旧档打开不报错；
- 375×667 下小屋 UI 无溢出、可滚动、可关闭。

## P2 鉴别 / 相似种（核心特色）

### 2.1 拟态对（只用现有物种）

| 安全种 | 危险拟态 | 现实原型 |
|---|---|---|
| button 双孢蘑菇 | angel 鳞柄白鹅膏 | 经典白菇误采 |
| straw 草菇 | deathcap 毒鹅膏 | 亚洲最常见中毒案 |
| morel 羊肚菌 | gyromitra 鹿花菌 | 春季经典易混 |

`js/data.js` 增加 `MIMICS={button:'angel', straw:'deathcap', morel:'gyromitra'}`。

### 2.2 生成

安全种刷出时 **18%** 概率实际是拟态个体：`m.trueId = MIMICS[m.spId]`，**渲染完全使用安全种的精灵**（外观无法区分——这正是玩法）。拟态个体不参与「保底未发现物种」逻辑。

### 2.3 观察（鉴别）交互

- 靠近蘑菇时提示变为「空格 采集 · F 观察」；触屏在采集钮上方出现「👁 观察」钮。
- 观察 → 角色蹲下 0.6s（复用采集蹲姿）→ 弹出**鉴别卡**（小面板，非全屏模态）：
  - 显示该蘑菇 3 条特征（菌褶颜色 / 菌环菌托 / 气味，由物种 art+edi 生成文案）；
  - 若是拟态：其中 1-2 条特征标红并写实差异（如「菌褶：纯白 ⚠ 双孢蘑菇的菌褶应为粉褐色」），卡片底部亮红字「⚠ 这不是双孢蘑菇——是鳞柄白鹅膏！」；
  - 若正常：绿字「✓ 特征相符，可以放心采」。
- 观察过的蘑菇头顶常驻小标记：✓（安全）或 ☠（拟态）。
- 观察后再采拟态 = 「识破采集」：按危险种入包（可入图鉴、药铺可卖），toast「戴上手套小心采下」，`mimicCaught++`。

### 2.4 误采后果

未观察直接采到拟态：
- 该拟态按危险种入包 + 全屏短震 + toast「⚠ 手一滑才发现是毒鹅膏！篮里 3 朵菇被毒液沾染了…」；
- 背包中随机 3 件可食物品被标记 `tainted:true`（图标variant灰化、售价 0、交付委托不可用），`mimicFooled++`；
- 小屋出售页可一键「丢弃污染菇」。

### 2.5 图鉴联动

三对物种详情页加互链行：「⚠ 极易与〈××〉混淆——鉴别要点：…」。

### 2.6 成就

`火眼金睛`（首次识破）、`学费`（首次被坑）、`鉴菇师`（识破 10 次）。

### 2.7 验收钩子

`__mh` 增：`spawnMimic(safeId)`（在玩家旁强制刷一株拟态）、`inspect()`（对 activeM 观察）、`mimics:()=>MIMICS`。

### 2.8 验收标准

- 强刷拟态后：外观与安全种一致（截图对比）；观察卡出现红字警示；识破采集入包为危险种；
- 未观察误采：3 件物品 tainted、售价 0、toast 出现；
- 正常个体观察显示绿字；观察标记 ✓/☠ 渲染在头顶；
- 触屏（无 hover 模拟）出现观察钮；成就三条可触发。

## P3 猎菇犬 + 工具店（花钱的地方）

### 3.1 道具店页签

| 道具 | 价格 | 效果 |
|---|---|---|
| 🐕 猎菇犬 | 400 | 跟随；嗅出埋藏菇与拟态（见 3.2） |
| 🥾 雨靴 | 120 | 雨天与湿地移速 +25% |
| ⛏ 小铲 | 150 | 埋藏土堆微光高亮，可视距离翻倍 |
| 🔍 放大镜 | 250 | 观察无需蹲下等待（即时出卡） |

| 🧺 大竹篮 I/II | 180 / 420 | 容量 25→40→60 |

一次性购买，`state.tools` 持久化；已购显示「✓ 已备下」。

### 3.2 猎菇犬

- **美术**：`js/player.js` 新增 `makeDog(dir,frame)` —— 与角色同风格的柴犬系小狗（奶油色+棕背、卷尾、红项圈），2 帧走姿 ×3 朝向，SS=2 超采样。
- **行为**（`render.js`）：落后玩家 ~46px 跟随（惰性插值×dtf）；玩家静止 4s 后坐下摇尾。
- **嗅探**：每片林地随机认领≤2 个目标（buried 蘑菇优先，其次拟态）；玩家进入目标 300px 内时，狗跑向目标、原地转圈+「汪！」（tone 合成吠声）+ 头顶 ❗，并在目标位置画淡金色嗅探圈 3s。每个目标只提示一次。
- 拟态目标被嗅出时 toast「小狗对着那朵菇低吼——不太对劲」。

### 3.3 成就

`最好的朋友`（买狗）、`鼻子比眼灵`（狗嗅出的松露/松茸被你挖到）、`装备齐全`（集齐全部道具）。

### 3.4 验收钩子

`__mh` 增：`buy(id)`（免费直购测试用）、`dog:()=>dogState`、`toolOwned(id)`。

### 3.5 验收标准

- 道具店可买、金币扣减、余额不足禁用、刷新后保留；
- 狗精灵美术验收（截图：三朝向+坐姿，风格协调）；跟随不抖动、不穿模到玩家前面挡视线；
- 强刷 buried 菇 → 靠近 → 狗指示行为完整触发；
- 雨靴/灯笼/大竹篮数值生效（速度测量、容量上限、灵境亮度截图对比）。

## P4 新鲜度 + 一天一局

### 4.1 天数

「深入林间」= 新的一天（`state.day++`，已在 P1 铺垫）。切换环境/季节不加天。

### 4.2 新鲜度

- 每件物品 `fr` 每过 1 天衰减：普通 −0.25；`inky/shaggy`（鬼伞类）−0.75（隔天基本化墨）；`truffle/reishi/woodear/enoki`（耐存）−0.10。下限 0。
- 售价乘 `(0.4+0.6×fr)`；出售列表显示新鲜度条（绿→黄→灰）；fr=0 的鬼伞显示为「已自融 🖤」售价 1。
- 委托交付要求 fr≥0.5 的个体。

### 4.3 日光节律（单日内）

- 进入林地起计时：**前 4 分钟白昼 → 1 分钟黄昏渐变 → 暮色**（整体色调经由现有 seasonTint 通道叠加暖橙→蓝紫；灯笼把白昼延长 2 分钟）。
- 入暮时提示一次「天色暗了——今天收获不错，回小屋看看吧」，并把「深入林间」按钮文案换成「🌙 歇一晚，明日再来」。**不强制结算、不惩罚**（保持治愈基调），暮色里萤火虫粒子加倍。
- 「歇一晚」= newField（天数+1、新鲜度结算、时价与委托刷新、天气预报兑现）。

### 4.4 天气预报

生成林地时同时预生成**明日天气**（同一 RNG 流），小屋顶部与入暮提示中显示「明日：🌧 有雨」。雨天预报是玩法信息（雨生种爆发）。

### 4.5 成就

`赶早市`（白昼结束前带 ≥8 朵回小屋卖出）、`墨色的教训`（让一朵鬼伞自融）、`月下归人`（暮色中仍采到 5 朵）。

### 4.6 验收钩子

`__mh` 增：`day:()=>state.day, setClock(sec)`（跳时钟）、`forecast()`。

### 4.7 验收标准

- setClock 快进：黄昏色调渐变自然（截图 3 张：白昼/黄昏/暮色）、提示出现、按钮文案切换；
- 跨天后 fr 下降数值正确、鬼伞速朽、售价随之变化、委托拒收 fr<0.5；
- 预报与次日实际天气一致；灯笼延时生效。

## P5 烹饪 buff

### 5.1 灶台页签

菜谱卡片：名称、所需食材（图标×数量）、效果说明、「开火」按钮（食材不足置灰）。做菜消耗**新鲜度最高**的对应食材，产出 buff（多数持续到明日结束，即 `until=state.day+1`）。已做过的菜点亮进「菜谱集」。

### 5.2 菜谱（10 道）

| 菜 | 食材 | 效果（至明日） |
|---|---|---|
| 小鸡炖蘑菇 | honey×3 | 移速 +15% |
| 松茸炊饭 | matsu×1 | 稀有运 ×1.5 |
| 黄油煎鸡油菌 | chant×3 | 蘑菇显形微光半径 +40% |
| 奶油蘑菇汤 | button/field 任意×4 | 背包临时 +5 格 |
| 红菇炖汤 | russula×2 | 观察即时（等效放大镜一天） |
| 椒盐马勃排 | puff×2 或 gpuff×1 | 委托报酬 +30% |
| 凉拌木耳 | woodear×3 | 雨天移速 +25% |
| 干煸见手青 | lanmao×2 | 90%：稀有运 ×2；10%：**见小人**（见 5.3） |
| 灵芝老鸭汤 | reishi×1 | 全增益各 +10% |
| 黑松露炖蛋 | truffle×1 | 明日保底 1 株 珍稀+ |

buff 存 `state.buffs`，spawn/移动/UI 各处读取；同类不叠加取高。

### 5.3 见小人（彩蛋）

触发后 20s：画面轻微波浪扭曲（渲染时对 ctx 做正弦位移条带）+ 屏幕边缘冒出跳舞小蘑菇人粒子（程序绘制，戴着小伞帽）+ BGM 短暂变速 0.9→1.1 摆动；**无任何负面数值**。toast「眼前……全是打着伞跳舞的小人！！」。成就 `见到小人了`。

### 5.4 成就

`第一口鲜`（首次做菜）、`见到小人了`、`满汉全菌`（10 道全做过）。

### 5.5 验收钩子

`__mh` 增：`cook(name)`（免材料测试开关 `cookFree=true`）、`buffs:()=>state.buffs`、`triggerXiaoren()`。

### 5.6 验收标准

- 每道菜：食材扣减正确（取最鲜）、buff 数值可测（速度/半径/容量/报酬实测）、跨天过期；
- 见小人特效截图验收（扭曲+小人可见、20s 后完全恢复、无残留）；
- 菜谱集持久化；三成就可触发。

## P6 品质 / 变异 / 拍照

### 6.1 品质

刷菇时投品质：普通 70% / **肥美** 25%（价×1.5，精灵 ×1.15）/ **极品** 5%（价×2.5，×1.3 + 常驻微金闪粒）。采集 toast 与出售行带品质前缀（肥美·极品用橙/金字）。图鉴详情记录「采过的最佳品质」。

### 6.2 变异

独立第二投：**白化** 1.5%（整体去饱和提亮，幽白）/ **鎏金** 0.8%（暖金色相）。实现：`paintMushroom(sp,SS,variant)` 对 art 色板做统一变换后绘制，精灵缓存 key 加变体后缀。变异个体发现时走小型发现特效（金框 toast + 音效），售价 ×5，图鉴物种卡角落点亮 ◇白 / ◆金 徽记。

### 6.3 拍照模式

- `#actions` 加 `📷` 钮：进入取景 → 游戏暂停、出现 3:2 取景框（可拖动，默认居中）→「咔嚓」（快门音 + 白闪）。
- 生成明信片：`canvas` 合成 —— 场景裁切 + 奶油色宽边 + 左下「菌踪」朱红印章（程序绘制篆刻风方印）+ 右下手写体日期行「第 N 天 · 秋 · 松针林」；若取景框内有蘑菇，边框上加该物种小邮票图。
- 产出：预览浮层 + 「保存图片」（toDataURL 下载 `junzong_day{N}.png`）。

### 6.4 成就

`菌中贵族`（首株极品）、`林间幽灵`（首株白化）、`点金手`（首株鎏金）、`山林摄影师`（拍 5 张）。

### 6.5 验收钩子

### 6.6 验收标准

- 三档品质、两种变异各强制生成一次：精灵美术逐一截图验收（白化要"幽"不要"脏"，鎏金要"暖"不要"荧光绿"）；
- 明信片 PNG 实际生成：构图/印章/文字排版验收；
- 概率写在常量表、图鉴徽记持久化。
