# 菌踪 · 蘑菇采集模拟器

一个纯前端 HTML5 蘑菇采集模拟器。打开 `index.html` 即可游玩，无需构建或依赖。

在线游玩：https://freefrank.github.io/mushroomhuntingsim/

## 玩法

- 背上竹篮，在随四季流转的山林里寻找并采集蘑菇，收集全部 **40 种**真实与幻想菌类。
- 移动：`WASD` / 方向键 / 触屏摇杆 / 鼠标或手指按住拖动；采集：`空格` / `E` / 采集钮 / 点击蘑菇（会自动走近采集）。
- 「深入林间」刷新一片新的林地并让山中的一天过去；季节与环境可随时切换（不消耗天数）。
- 竹篮容量 25 朵，满了要去山脚小屋卖掉些才能继续采。

## 市集与委托

- 山脚 🏠 小屋 内设「出售」「委托」两个页签，采到的蘑菇要拿去这里才能变成真正的收获。
- **出售**：按物种聚合列出背包内容，单价随物种稀有度、食毒性与每日浮动的「时价」（↑涨 ↓跌）变化，可单种卖出或「一键全卖」；毒菇、剧毒由「⚗ 药铺」代收，纯风味说法。
- **委托**：小屋常驻 3 张委托单，山民、药铺伙计、客栈厨娘等各色乡邻会指名要几朵当季蘑菇，凑够数量即可交付换取报酬，交付后立即补上新的一单；委托过期或换季换环境导致凑不齐也无妨，它会自然作废重开。
- 金币、背包、委托进度均随存档持久化；卖出与委托解锁「首笔生意」「小有积蓄」「金字招牌」三项新成就。

## 鉴别与相似种

- 三种常见安全菇（双孢蘑菇、草菇、羊肚菌）各有一个外观**完全相同**的危险拟态（鳞柄白鹅膏、毒鹅膏、鹿花菌）——安全种刷出时约 18% 概率其实是拟态个体，靠肉眼无法分辨。
- 靠近蘑菇时按 `F`（触屏点竹篮采集钮上方的「👁 观察」钮）可以观察：角色蹲下片刻后弹出鉴别卡，列出菌褶颜色、菌环菌托、气味三条特征；若是拟态，会有 1-2 条标红并写明与安全种的差异，底部给出结论——识破的拟态会标红警示，安全个体则是绿字放行。观察过的蘑菇头顶会留下常驻的 ✓ / ☠ 小标记。
- 识破后再采拟态会按真实（危险）物种入包，可入图鉴、送药铺代卖；若没观察就误采，会有画面短震与警示提示，背包里随机 3 朵可食蘑菇被「污染」（售价归零、无法用于委托交付），可在小屋出售页一键丢弃。
- 图鉴详情页会互相提示「极易与〈××〉混淆」，成就新增「火眼金睛」「学费」「鉴菇师」。

## 工具与猎菇犬

- 山脚小屋新增「道具店」页签，可花金币一次性购入 7 件道具：🐕 猎菇犬、🥾 雨靴、⛏ 小铲、🔍 放大镜、🏮 灯笼、🧺 大竹篮 I / II（大竹篮 II 需先备好大竹篮 I），已购项会显示「✓ 已备下」，金币不足时按钮禁用，购买记录随存档持久化。
- **猎菇犬**：手绘水彩风的柴犬系小狗，奶油底色配棕色背斑、竖耳、卷尾与红项圈，跟在玩家身后 46px 处惰性跟随，玩家静止 4 秒后会坐下摇尾；每片林地会为它随机认领至多 2 个嗅探目标（优先埋藏的土堆，其次是拟态菇），玩家靠近 300px 内时狗会跑过去原地转圈、「汪」两声、头顶亮起 ❗ 并在目标处泛开一圈淡金色嗅探光晕，同时弹出提示——每个目标只提示一次。
- **雨靴**：雨天或身处溪谷湿地时移动速度 +25%。
- **小铲**：埋藏土堆的可视（可被发现）距离翻倍，土堆还会带一层淡金微光。
- **放大镜**：观察蘑菇无需再蹲下等待，直接弹出鉴别卡。
- **灯笼**：灵境秘林的画面更明亮、暗角更浅。
- **大竹篮 I / II**：背包容量 25 → 40 → 60。
- 新增成就「最好的朋友」（购入猎菇犬）、「鼻子比眼灵」（采到猎菇犬提示过的埋藏蘑菇）、「装备齐全」（集齐全部 7 件道具）。

## 一天一局与新鲜度

- 每次点击「深入林间」（暮色中会变为「🌙 歇一晚，明日再来」）都会推进一天：背包里每件蘑菇按物种档位扣新鲜度 `fr`（普通 −0.25，墨汁鬼伞/毛头鬼伞速朽 −0.75，黑松露、灵芝、木耳、金针菇耐存 −0.10，下限 0），同时刷新时价与委托、兑现天气预报。
- **新鲜度与售价**：出售页签按物种堆叠展示，堆内每件按各自 `fr` 计价再加总，行内附一条绿（≥0.7）／黄（≥0.4）／灰（<0.4）的新鲜度小色条；鬼伞类新鲜度耗尽会写作「已自融 🖤」，单价固定为 1。
- **委托只收新鲜货**：交付与「持有」数只统计 `fr≥0.5` 且未被污染的个体，放久了的蘑菇送不出去。
- **日光节律**：进入一片林地起计时，前 4 分钟（备有 🏮 灯笼延长到 6 分钟）是白昼，之后 1 分钟画面渐渐染上黄昏的暖橙、再转为深蓝紫的暮色并小幅加深暗角，入暮的一刻会提示一次「天色暗了」并附带明日天气预报，暮色里流萤翻倍——全程不强制结算、不惩罚，只是提醒你该回小屋了。
- **天气预报**：小屋面板顶部常显「明日：🌧 有雨」之类的预告，与次日实际出现的天气完全一致，方便提前规划该采雨生种还是躲雨。
- 新增成就「赶早市」（白昼结束前单日卖出 8 朵）、「墨色的教训」（放到自融的鬼伞）、「月下归人」（暮色中仍采到第 5 朵）。

## 灶台与山间食单

- 山脚小屋新增「灶台」页签：10 道菜谱卡片，列出所需食材（图标 ×数量）、效果一句话与「🔥 开火」按钮——食材不够会置灰并标注还缺什么；做过的菜会在卡片角落点亮 ✓，页签头显示「已解锁 n/10」。
- 做菜会消耗背包中该物种**新鲜度最高**（`fr>=0.5` 且未被污染）的对应件数；「奶油蘑菇汤」这类"双孢/四孢任意×4"的混合食材，会在两个物种的合并池里取最鲜的 4 件。
- 十道菜与效果（均持续到明日结束，跨天由「深入林间」结算过期）：
  - 🍲 小鸡炖蘑菇（蜜环菌×3）→ 移速 +15%
  - 🍚 松茸炊饭（松茸×1）→ 稀有运 ×1.5
  - 🧈 黄油煎鸡油菌（鸡油菌×3）→ 蘑菇显形范围 +40%
  - 🥣 奶油蘑菇汤（双孢/四孢任意×4）→ 背包临时 +5 格
  - 🍵 红菇炖汤（正红菇×2）→ 观察即时出卡，等效放大镜一天
  - 🍖 椒盐马勃排（马勃×2 或 巨型马勃×1）→ 委托报酬 +30%
  - 🥗 凉拌木耳（木耳×3）→ 雨天移速 +25%（与雨靴叠乘）
  - 🌶️ 干煸见手青（见手青×2）→ 90% 稀有运 ×2；10% 触发「见小人」彩蛋（附赠稀有运 ×1.2）
  - 🍜 灵芝老鸭汤（灵芝×1）→ 移速 +5%／稀有运 +10%／显形范围 +10%
  - 🍳 黑松露炖蛋（黑松露×1）→ 明日保底刷出 1 株珍稀（★★★+）蘑菇
- 同名增益重做会刷新有效期并取较高数值；「见小人」触发后 20 秒内画面轻微波浪扭曲、屏幕边缘冒出跳舞的小蘑菇人、背景音乐短暂变速摆动，全程没有任何负面效果，结束后完全恢复。
- 新增成就「第一口鲜」「见到小人了」「满汉全菌」。

## 品质、变异与拍照

- **品质**：每株蘑菇刷出时会投一次品质——普通 70% / 肥美 25%（售价 ×1.5，精灵略大 ×1.15）/ 极品 5%（售价 ×2.5，精灵 ×1.3 且伞盖周围常驻 2-3 点缓慢闪烁的微金星点）。采集提示与出售行会用橙/金字标出「肥美」「极品」前缀。
- **变异**：与品质相互独立的第二次投骰——白化 1.5%（整体去饱和、大幅提亮，呈冷白微青，不是脏灰）/ 鎏金 0.8%（色相统一转暖金琥珀，保留原有明暗层次）。变异个体售价额外 ×5，且与品质倍率相乘（例如「极品·白化」＝ ×2.5×5＝×12.5）。采到变异个体会触发一次小型发现特效（金色描边 toast + 专属音效），不打断游戏。
- 图鉴会记录每个物种「采过的最佳品质」，遇到过的变异会在物种卡角落点亮 ◇（白化）／◆（鎏金）小徽记，详情页也会列出。
- **拍照模式**：点击 📷 拍照 进入取景——游戏暂停，出现一个可拖动的 3:2 取景框（默认居中，约视口短边 70%，四角带 L 形取景标）；点「咔嚓 📸」触发白闪与快门声，程序化合成一张明信片：场景裁切 + 奶油色宽边 + 左下朱红篆刻风「菌踪」方印 + 右下手写体日期行「第 N 天 · 秋 · 阔叶林」，若取景框内有已发现的物种，还会在照片右上角贴一枚该物种的虚线小邮票。预览浮层可「保存图片」（下载 `junzong_day{N}.png`）或「再拍一张」。
- 新增成就「菌中贵族」（首株极品）、「林间幽灵」（首株白化）、「点金手」（首株鎏金）、「山林摄影师」（拍满 5 张）。

## 特色

- **手绘水彩风画面**：矢量绘制的场景与蘑菇（菌褶、菌环、菌托、鳞片、疣点、蜡质光泽、荧光……），柔和光影、体积光、季节色调与天气粒子（雨、雪、落叶、飞雾、流萤）。
- **真实生态**：每种蘑菇都按其真实生态放置——
  - 木生菌（香菇、平菇、金针菇、木耳）只长在倒木与树桩上；
  - 菌根菌长在宿主树下（毒蝇伞配桦树、松茸埋在松树下、鸡油菌伴栎树）；
  - 春天出羊肚菌，盛夏见手青，秋季是盛季，冬天去枯木上找平菇、栎树下掘黑松露；
  - 雨后木耳、鬼伞、正红菇大量萌发；草甸上会出现「仙女环」蘑菇圈；
  - 冬季的松林与草甸几乎无菇——这是真实的，提示会告诉你该去哪。
- **五种环境**：阔叶林、草甸、松针林、溪谷湿地，以及解锁后的幻想环境「灵境秘林」。
- **图鉴与成就**：40 种蘑菇的图鉴（含生境、宿主、时节、食毒性与风物志，互链拟态混淆提示），25 项成就，进度自动存档。
- **每个环境一首原创 BGM**：切换环境时 1.4 秒交叉淡入淡出，静音按钮同步控制音乐与音效。

## 技术

纯原生 JavaScript + Canvas 2D，所有美术均为运行时程序化绘制，无任何外部资源依赖（字体为渐进增强）。画面视口随设备尺寸与纵横比自适应，支持高分屏。

```
index.html        页面骨架
css/style.css     界面样式
js/utils.js       颜色/随机数等工具
js/data.js        物种生态数据（40 种）
js/mushrooms.js   蘑菇矢量绘制引擎与精灵缓存
js/state.js       进度存档
js/audio.js       环境音与音效
js/player.js      角色绘制
js/world.js       场景装饰、地面烘焙、生态化地图生成
js/render.js      渲染主循环、天气与光效
js/market.js      市集定价、委托生成、道具店、灶台烹饪 buff 与小屋（出售/委托/道具店/灶台）UI
js/game.js        采集/图鉴/成就/输入/启动
assets/bgm/       各环境背景音乐（forest/meadow/pine/wetland/grove）
```
