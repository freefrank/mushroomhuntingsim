# 菌踪 · 蘑菇采集模拟器

一个纯前端 HTML5 蘑菇采集模拟器。打开 `index.html` 即可游玩，无需构建或依赖。

在线游玩：https://freefrank.github.io/mushroomhuntingsim/

## 玩法

- 背上竹篮，在随四季流转的山林里寻找并采集蘑菇，收集全部 **40 种**真实与幻想菌类。
- 移动：`WASD` / 方向键 / 触屏摇杆 / 鼠标或手指按住拖动；采集：`空格` / `E` / 采集钮 / 点击蘑菇（会自动走近采集）。
- 「深入林间」刷新一片新的林地；季节与环境可随时切换。

## 特色

- **手绘水彩风画面**：矢量绘制的场景与蘑菇（菌褶、菌环、菌托、鳞片、疣点、蜡质光泽、荧光……），柔和光影、体积光、季节色调与天气粒子（雨、雪、落叶、飞雾、流萤）。
- **真实生态**：每种蘑菇都按其真实生态放置——
  - 木生菌（香菇、平菇、金针菇、木耳）只长在倒木与树桩上；
  - 菌根菌长在宿主树下（毒蝇伞配桦树、松茸埋在松树下、鸡油菌伴栎树）；
  - 春天出羊肚菌，盛夏见手青，秋季是盛季，冬天去枯木上找平菇、栎树下掘黑松露；
  - 雨后木耳、鬼伞、正红菇大量萌发；草甸上会出现「仙女环」蘑菇圈；
  - 冬季的松林与草甸几乎无菇——这是真实的，提示会告诉你该去哪。
- **五种环境**：阔叶林、草甸、松针林、溪谷湿地，以及解锁后的幻想环境「灵境秘林」。
- **图鉴与成就**：40 种蘑菇的图鉴（含生境、宿主、时节、食毒性与风物志），16 项成就，进度自动存档。

## 技术

纯原生 JavaScript + Canvas 2D，所有美术均为运行时程序化绘制，无任何外部资源依赖（字体为渐进增强）。画面视口随设备尺寸与纵横比自适应，支持高分屏。

```
index.html        页面骨架
css/style.css     界面样式
js/utils.js       颜色/随机数等工具
js/data.js        物种生态数据（40 种）
js/mushrooms.js   蘑菇矢量绘制引擎与精灵缓存
js/state.js       进度存档
js/audio.js       环境音与音效
js/player.js      角色绘制
js/world.js       场景装饰、地面烘焙、生态化地图生成
js/render.js      渲染主循环、天气与光效
js/game.js        采集/图鉴/成就/输入/启动
```
